# Cleaned Data
 
This folder contains the cleaned frailty dataset used for analysis.
 
## File
 
- `clean_frailty_data.csv` – Cleaned version of the original frailty dataset.
 
## Data Cleaning
 
The raw dataset was cleaned and prepared for analysis by:
 
- Removing extra spaces from column names
- Removing whitespace from the numerical values
- Converting Height, Weight, Age, and Grip strength from object data types to numeric data types
- Cleaning and standardizing the Frailty values to Y and N
- Checking for missing values
- Checking for duplicate rows
- Verifying the dataset shape before and after cleaning
 
## Purpose
 
The original dataset is preserved in the `data_raw` folder. The cleaned dataset contains the prepared data that is used for the statistical analysis in this project.
