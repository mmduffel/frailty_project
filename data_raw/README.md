# Raw Data
 
This folder contains the original frailty dataset used for this project.
 
## Dataset
 
- `raw_frailty_data.csv` – Original frailty dataset before data cleaning or preprocessing.
 
## Purpose
 
The raw dataset is kept unchanged to preserve the original data. The dataset is uploaded into Google Colab and loaded using Python and pandas for review and preprocessing.
 
Any data cleaning or preparation is performed separately, with the cleaned dataset saved in the `data_clean` folder.
